## Delivery: the library NestForge assembles
YOU ARE NOT ALLOWED TO EDIT C++ CODE DIRECTLY, unless the workflow gives you the Kernel code phase. You shape the
program with the NestForge tools, and it is built into a prebuilt shared library `{{ lib_name }}` exporting
`{{ symbol }}` in the shared folder `{{ shared_dir }}`.

`score` previews the program as it stands and `submit` records it; neither takes arguments.
