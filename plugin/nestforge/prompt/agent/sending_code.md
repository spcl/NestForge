## Sending code

YOU ARE NOT ALLOWED TO EDIT C++ CODE DIRECTLY. You change the program only with the NestForge tools; there is no shell,
and neither `score` nor `submit` takes code. The one exception is the Kernel code phase, when the workflow gives it to
you: there `write_kernel` replaces a kernel's source.

`score` and `submit` take no arguments: each finalizes the program as your moves left it and grades that library.
`finalize` alone builds it for `profile`.
