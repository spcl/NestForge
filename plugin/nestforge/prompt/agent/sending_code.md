## Sending code

YOU ARE NOT ALLOWED TO EDIT C++ CODE DIRECTLY. You change the program only with the NestForge tools; there is no shell,
and neither `score`, `submit` nor `profile` takes code. The one exception is the Kernel code phase, when the workflow gives it to
you: there `write_kernel` replaces a kernel's source.

`score` and `submit` take no arguments and `profile` only its instrument: each finalizes the program as your moves left
it and works on that library.
